Интерфейс lo (loopback device) — это локальная петля, которая имеет IP-адрес 127.0.0.1 и используется для отладки сетевых программ и запуска серверных приложений на локальной машине.

DHCP - Dynamic Host Configuration Protocol (протокол динамической конфигурации хоста).

`ip route` `route -n` - выводит внутренний IP-адрес шлюза, он же ip-адрес по умолчанию (gw).

## Part 8. Установка и базовая настройка сервиса SSHD

- Командой `sudo apt install openssh-server` установим службу SSHd.

![8.1](screeshots/8.1.PNG)

- Чтобы включить автостарт можно воспользоваться командой `sudo systemctl enable ssh`.

![8.2](screeshots/8.2.PNG)

- Чтобы перенастроить службу SSHd на порт 2022, введем команду `sudo nano /etc/ssh/sshd_config`. Далее заменяем #Port 22 на Port 2022.

![8.4](screeshots/8.4.PNG)

- Используя команду `ps aux | grep sshd`, покажем наличие процесса sshd.

![8.6](screeshots/8.6.PNG)

Для мониторинга процессов в Linux предназначена команда ps. aux состоит из трех опций: опция a обеспечивает отображение всех процессов, опция u предоставляет расширенную информацию об использовании, а опция x показывает, с какого TTY и каким пользователем запускается процесс.

- Перезапустим сервер командой `sudo systemctl restart ssh` и проверим изменения командой `netstat -tulpan | grep 2022`.
- Введем команду `netstat -tan`.

![8.5](screeshots/8.5.PNG)

- Netstat, сокращение от “статистика сети”, - это инструмент командной строки в Linux, который предоставляет подробную информацию о сетевых подключениях, таблицах маршрутизации, статистике сетевого интерфейса. 
    - t: показывает TCP-соединения;
    - a: отображает все активные подключения и порты прослушивания;
    - n: отображает адреса и номера портов в числовой форме, а не преобразует их в имена хостов и служб.

- Значение каждого столбца вывода `netstat -tan`:
    - Proto — сетевой протокол (tcp, udp);
    - Recv-Q — количество байтов, помещённых в буфер приёма TCP/IP, но не переданных приложению;
    - Send-Q — количество байтов, помещённых в буфер отправки TCP/IP, но не отправленных, или отправленных, но не подтверждённых;
    - Local Address — локальный адрес сервера;
    - Foreign Address — адрес второй стороны;
    - State - состояние соединения (LISTEN, ESTABLISHED, etc.).

Значение 0.0.0.0 в Local Address и Foreign Address означает, что подключаться можно с любых адресов и с любых портов.
